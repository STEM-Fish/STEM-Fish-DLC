角色立绘替换（主菜单 / 世界生成界面）

======================================



规则：**PNG 文件名 = 场景对象名 或 sprite 名**（两种都认），放在本目录下即可。

程序直接挂 `Image.sprite` 的赋值钩子：谁往那个 Image 里塞图都会被当场换成你的，

所以不会再和原版逐帧动画抢图（v0.16 的闪烁就是这么来的）。



尺寸：导出时已经**按原版 sprite 的画布尺寸**铺好了 —— 角色在画布里的位置就是游戏里的位置。

只要**保持画布尺寸和比例**，你画多大都行（等比放大即可），程序会按原版几何重建 sprite。

开场下坠动画（GenCharacter）
────────────────────────────────────────────────────────
开局生成世界时，那只坐在下坠舱里、和舱体一起抖动的角色也是 GenCharacter，
但它在这一段用的是另一张图：**genexpnew**（不是 genexpnewalt）。

两张原图逐像素一致（都是 320×180，角色在同一位置），所以默认规则是：
  sprite 'genexpnew' 找不到同名 PNG → 自动回退到 genexpnewalt.png
也就是说：**你画的 genexpnewalt.png 会同时管这两处**，不用画第二份。

如果你想给下坠段单独画一张（比如加抖动/受力姿势）：
  把 _reference/genexpnew.png 复制到上一层并改名 genexpnew.png，重画即可；
  同名文件优先级比 "genexpnewalt 回退" 高，会立刻接管这一段。
